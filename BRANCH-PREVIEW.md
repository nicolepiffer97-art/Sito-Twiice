# Home parallax preview

Branch: `preview-parallax`.

Live branch preview: https://raw.githack.com/nicolepiffer97-art/Sito-Twiice/preview-parallax/dist/index.html

The home adds three scroll depths (sky, logo and payoff), a subtle pointer response on desktop, section entrances and a small movement inside the highlighted project image. Mobile uses lower travel distances. Reduced-motion disables these effects.
